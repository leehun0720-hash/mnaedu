# 홈페이지 빌더 사용 안내

이 문서는 **운영하는 쪽**을 위한 것입니다. 실제 쓰는 방법은 도구 안에 들어 있습니다.

## 먼저 — 설명은 화면 안에 있습니다

`/builder` 를 여시면 오른쪽 위에 세 가지가 있습니다.

| 단추 | 하는 일 |
| --- | --- |
| **▸ 따라 하기** | 화면의 그 자리를 짚어 주며 열 걸음으로 직접 해 봅니다. 처음 열면 저절로 시작됩니다. |
| **? 사용법** | 전체 매뉴얼 8장. 차례를 눌러 이동하고, 인쇄도 됩니다. |
| 메뉴 옆 작은 **?** | 그 메뉴만 설명하는 쪽지. 13곳에 있습니다. |

고객에게 건네실 때는 「따라 하기」만 알려 주시면 됩니다. 읽는 것보다 빠릅니다.

---

## 1. 30분 만에 사이트 한 벌 만들기

1. **템플릿을 고릅니다.** 위쪽 「템플릿」 → 여섯 가지 중 고객에게 가까운 것.
   - TEN AI 소개 / AI 교육 과정 / AX 컨설팅 / 중소기업 회사 소개 / 공공기관 사업 안내 / 빈 문서
2. **글자를 고칩니다.** 캔버스의 글자를 직접 누르면 커서가 생깁니다.
   `Enter` 확정, `Esc` 되돌리기.
3. **색을 맞춥니다.** 왼쪽 「테마」 → 견본 다섯 가지. 고객 로고 색이 있으면
   강조색만 직접 지정하셔도 충분합니다.
4. **필요 없는 구역을 숨깁니다.** 왼쪽 「구역」 목록에서 ● 를 누르면 숨겨집니다.
   지우지 않고 숨기면 나중에 되살릴 수 있습니다.
5. **PC·태블릿·모바일을 확인합니다.** 위쪽 기기 단추로 넘겨 봅니다.
6. **내보냅니다.** 「HTML 내보내기」 → 파일 하나가 떨어집니다. 그 파일만 있으면
   어디에 올려도 그대로 뜹니다.

## 2. 작업을 이어서 하려면

- 작업물은 **브라우저에 자동으로 저장**됩니다. 같은 브라우저에서 다시 열면 그대로입니다.
- 다른 기기로 옮기거나 보관하시려면 「저장(JSON)」 으로 파일을 내려받고,
  옮긴 곳에서 「불러오기」로 되읽으십시오.
- **다른 브라우저·다른 PC 에서는 이어지지 않습니다.** 서버에 두지 않기 때문입니다.
  고객 작업물은 JSON 으로 받아 보관하시는 편이 안전합니다.

## 3. 내보낸 파일을 올리는 곳

HTML 한 장이므로 거의 어디에나 올라갑니다.

| 방법 | 언제 |
| --- | --- |
| 고객의 기존 웹호스팅에 파일 복사 | 이미 도메인이 있을 때 |
| Vercel·Netlify 에 폴더째 끌어놓기 | 새 주소가 필요할 때 (무료) |
| 메일·메신저로 파일 전달 | 시안을 먼저 보여 드릴 때 |

이미지는 파일 안에 함께 담기므로 사진이 깨지지 않습니다. 대신 사진을 많이 넣으면
파일이 커집니다 — 시안 단계에서는 2~3장으로 충분합니다.

## 4. 게시판을 넣었을 때

게시판 구역을 넣으면 내보낸 HTML 안에서 **글쓰기가 그대로 돕니다.** 다만 서버가
없으므로 글은 **그 글을 쓴 사람의 브라우저에만** 남습니다.

- 공지·안내처럼 **미리 넣어 두는 글**은 빌더에서 넣으십시오. 모두에게 보입니다.
- 방문자끼리 글을 주고받는 진짜 게시판이 필요하면 서버가 있어야 합니다.
  그때는 텐에이아이에 문의하십시오.

## 5. 고객에게 설명할 때 쓰는 말

> "지금 보시는 이 화면이 그대로 결과물입니다. 마음에 안 드는 글자를 짚어 주시면
> 그 자리에서 고쳐 보여 드리겠습니다."

빌더의 값은 **고치는 속도**에 있습니다. 회의 중에 고쳐서 바로 보여 드리는 것이
시안을 세 번 주고받는 것보다 낫습니다.
